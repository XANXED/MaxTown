# Правила интерфейса MaxTown

Инструкция для интерфейсов VK Mini App и Moderator Admin. Исторические материалы
MAX в `design/stitch/` не задают платформу или компоненты текущего приложения.

## Стек Mini App

- Основные компоненты — `@vkontakte/vkui`; корневой shell настраивается через
  `ConfigProvider`, `AdaptivityProvider` и `AppRoot`.
- Вызовы VK Bridge держать в `apps/miniapp/src/platform/` либо в узких
  адаптерах. Не читать `window` напрямую из произвольных экранов.
- Инициализировать VK Bridge при старте. Параметры запуска передавать API для
  серверной проверки подписи; имя/фото из `VKWebAppGetUserInfo` — только для
  отображения, они не подтверждают учётную запись.
- VKUI отвечает за платформенные контролы, тему и адаптивность. Не подменять
  системную тему собственной палитрой или жёстко заданной темой.
- Для поведения, не покрытого VKUI, используйте компоненты из
  `apps/miniapp/src/components/ui.tsx` и токены `design/tokens.css`.

## Токены и стили

> В собственном CSS не задавайте литералами цвета, размеры шрифта, радиусы и
> отступы. Используйте `var(--…)` из `design/tokens.css` или токены VKUI.

```css
/* нельзя */
color: #060708;
border-radius: 16px;
padding: 12px 16px;

/* можно */
color: var(--text-primary);
border-radius: var(--radius-16);
padding: var(--space-12) var(--space-16);
```

Допустимы значения, для которых нет токена: `1px` для границы, `0`, проценты,
`auto`, `flex`/`grid` и технические значения вроде `100%`. Не создавайте новые
палитры и не добавляйте тяжёлые тени, градиенты или постоянную анимацию без
продуктовой причины.

Токены подключаются через алиас Vite:

```ts
import '@design/tokens.css';
```

Платформенные стили VKUI подключаются отдельно из `@vkontakte/vkui`.
При конфликте визуальных решений ориентируйтесь на VKUI и системную тему.

## Геометрия и доступность

- Экран должен помещаться в узкий viewport и учитывать safe-area/insets,
  переданные VK Bridge/VKUI. Не фиксируйте высоту экранов с текстом.
- Основные действия должны иметь доступные подписи; иконки без текста получают
  `aria-label`. Состояния загрузки, ошибки, пустых данных и повтора должны быть
  различимы.
- Не ломайте клавиатурную навигацию и системный масштаб текста.
- Текст интерфейса — на русском. Не обещайте доступность возможностей VK,
  если приложение не может проверить соответствующее разрешение/состояние.

Перед изменением интерфейса сначала изучите существующие компоненты и токены,
затем проверьте сборку Mini App.
