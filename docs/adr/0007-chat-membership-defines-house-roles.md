# Роли Дома выводятся из Домового чата

Статус: принято для хакатона, 28 сентября 2026 года. Заменяет модель Ролей из ADR 0001, ADR 0002 и ADR 0006.

В Доме используются три Роли: Администратор Дома, Жилец и УК. Добавивший MaxTown человек и все текущие администраторы либо владельцы Домового чата получают роль Администратора Дома; явно назначенный Администратором аккаунт участника чата получает роль УК; остальные участники получают роль Жильца. Роли пересчитываются при входе по актуальному составу чата, а назначение УК хранится по стабильному MAX user ID внутри конкретного Дома. Это упрощает хакатонный вход ценой отказа от отдельного подтверждения Жильца через Квартиру и от прежних Ролей Старосты, Консьержа и Ответственного.
