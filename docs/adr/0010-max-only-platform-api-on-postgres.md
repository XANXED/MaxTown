# MaxTown работает только в MAX; вся логика — в API на Postgres, Worker лишь проксирует

Статус: принято 29 сентября 2026 года. Заменяет спецификацию
`docs/superpowers/specs/2026-09-maxtown-vk-community-design.md` (переход на VK
владелец не утверждал) и хранение Домовых чатов в Workers KV из ADR 0004.
Публичный адрес уточнён ADR 0011: продакшн — maxtown.ru на сервере Timeweb,
Cloudflare Worker остаётся запасным.

## Контекст

Проект делается для MAX. В `main` приложение успели перевести на VK: вход по
подписи параметров VK, VK Bridge, бот и уведомления через VK. Параллельно в
ветке `feature/max-house-auth` появились вход через `initData` MAX, Домовые чаты,
Роли по составу чата и Адрес Дома из DaData — но на Cloudflare Worker с KV, без
Postgres, где живут Опросы, режим ремонта, услуги, Контакты, Места и Поставщики.

## Решение

- Платформа одна — MAX. Мини-апп входит по подписанному `initData`; VK Bridge,
  подпись параметров VK и VK Callback API удалены. VKUI остаётся как библиотека
  интерфейса: MAX сделан VK и выглядит так же.
- Единственный бэкенд — `apps/api` (Fastify + Postgres). В него перенесены
  webhook бота, Подключение Дома, Роли по чату (ADR 0006, 0007) и DaData.
  Домовые чаты хранятся в таблицах `house_chats` и `house_chat_onboardings`.
- Дом по-прежнему имеет uuid; граница данных — Домовой чат: `chat_id`
  уникален и связан ровно с одним Домом. Дубли адресов допустимы (ADR 0006).
- Роли в БД: `admin`, `resident`, `management-company`. Одна активная Роль
  на Дом; совмещение Администратора и УК хранится как `admin`. Членства
  пересчитываются при каждом входе; если MAX не ответил, прежнее остаётся.
- Квартира необязательна: Роль даёт участие в чате, Приглашение лишь
  привязывает Жильца к Квартире.
- Новый Опрос — одно сообщение бота в Домовой чат с кнопкой «Проголосовать»
  (`startapp=poll_<Дом>_<Опрос>`). Личных рассылок нет.
- Cloudflare Worker (`apps/edge`) остаётся публичным адресом, известным MAX:
  отдаёт статику и пересылает `/api/*` в API (`API_ORIGIN`). Логики в нём нет.
- Точку Дома даёт DaData при Подключении Дома; геокодер 2ГИС — запасной путь.

## Последствия

- Все прежние сессии (выданные по VK) отозваны миграцией 0012; личности VK в
  MAX не переносятся.
- Регистрация Дома Старостой и панель Модератора остались в API, но из
  мини-аппа убраны: Дома появляются из Домовых чатов.
- MAX API подписан Russian Trusted Root CA. Node без него уходит на запасной
  домен `platform-api.max.ru` (как ADR 0004); надёжнее добавить корень
  Минцифры в `NODE_EXTRA_CA_CERTS`.
- API на Render во Франкфурте: MAX оттуда отвечает, а 2ГИС с иностранного IP —
  нет (ADR 0008). Для Ближайших мест нужен хостинг в России.
- Локально `npm run local` подписывает ссылки входа тем же `BOT_TOKEN`, что
  проверяет API; без настоящего токена Домовые чаты MAX недоступны.
