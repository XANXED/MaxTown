# Все Роли работают в мини-аппе, веб-админка — только для Модератора

Староста, Ответственный и Консьерж работают в том же VK Mini App, что и Жилец:
разделы появляются по Роли. Вход использует проверенные сервером параметры
запуска VK Mini Apps, мастер работает с телефона, а уведомление VK-бота открывает нужную Заявку. Мы отказались от веб-админки для УК: ей нужен был бы свой вход вне VK,
и получилось бы два интерфейса на одни и те же действия. `apps/admin` остаётся
только для Модератора, который проверяет новые Дома.
