# Все Роли работают в мини-аппе, веб-админка — только для Модератора

Статус: заменено ADR 0007.

Староста, Ответственный и Консьерж работают в том же мини-аппе, что и Жилец:
разделы появляются по Роли. Вход через MAX ничего не стоит (личность подтверждает
`initData`), мастер работает с телефона, а уведомление бота открывает нужную
Заявку. Мы отказались от веб-админки для УК: ей нужен был бы свой вход вне MAX,
и получилось бы два интерфейса на одни и те же действия. `apps/admin` остаётся
только для Модератора, который проверяет новые Дома.
