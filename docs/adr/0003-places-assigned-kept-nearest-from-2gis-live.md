# Места рядом: Закреплённые храним у себя, Ближайшие берём из 2ГИС вживую без кеша

«Места рядом» делятся на две части с разными источниками. Закреплённые места
(поликлиника по прикреплению, школа по территории, избирательный участок,
мировой судья, участковый пункт) ведёт Староста, они хранятся в нашей базе:
закрепление за адресом не знает ни один картографический сервис. Ближайшие
места (травмпункт, больница, дежурная аптека, МФЦ, ветклиника) `apps/api`
запрашивает в 2ГИС Places API при каждом открытии экрана и **ничего не
сохраняет**: правила API 2ГИС запрещают «сохранять, обрабатывать, изменять»
полученные данные, кешировать разрешено только результаты геокодирования
(https://law.2gis.ru/api-rules). Прокси через `apps/api` нужен, чтобы ключ
Places не попадал в клиент, — но без кеша, снимков и правок Старосты поверх
данных 2ГИС.

## Considered Options

- **OpenStreetMap через Overpass, снимок на Дом** (так было в ранней версии мини-аппа для MAX):
  хранить разрешено (ODbL), бесплатно, но в малых городах данных об
  организациях мало и часы работы часто устаревшие. Отказались ради полноты
  и часов работы 2ГИС.
- **2ГИС с кешем на часы или сутки** (как предлагало исследование
  `docs/research/2gis-maps-api.md`): дешевле и быстрее, но нарушает правила API.

## Consequences

- Каждое открытие экрана — платные запросы к Places (биллинг по успешным
  ответам); без сети или ключа Ближайших мест нет, Закреплённые — есть.
- Бесплатное использование 2ГИС разрешено только некоммерческое, демо-ключ
  живёт 30 дней. Для запуска нужен договор с 2ГИС (content@2gis.ru).
- Каждый показ данных 2ГИС сопровождается атрибуцией «Работает на API 2ГИС».
- Скрыть неверное Ближайшее место Староста не может: для этого пришлось бы
  хранить данные 2ГИС. Если понадобится, сначала уточнить у 2ГИС, можно ли
  хранить хотя бы id организации.
- Ближайшие места одного Вида запрашиваются, только когда Жилец открывает
  этот Вид: один платный запрос на нажатие, а не десять на открытие вкладки.
  Объединить Виды в один запрос не выходит: демо-ключ отдаёт не больше
  10 результатов, и частые Виды вытесняют редкие.
- Точку Дома API получает геокодером 2ГИС и держит в памяти сутки (разрешённый
  временный кеш геокодирования); в базу она не пишется.
- Телефонов организаций у Ближайших мест нет: поле `contact_groups` требует
  отдельного разрешения ключа.
- Карта — 2ГИС MapGL JS в браузере Жильца, её ключ (`VITE_DGIS_API_KEY`)
  виден в коде страницы. Пока это тот же ключ, что у API; перед публикацией его
  нужно ограничить по домену мини-аппа в кабинете 2ГИС или завести отдельный.
- Точку Закреплённого места Староста ставит на карте сам — это его ввод, а не
  данные 2ГИС, поэтому она хранится вместе с местом.
- 2ГИС не отвечает на запросы с иностранных IP (проверено через VPN). Карте это
  не мешает — она грузится с устройства Жильца, — но серверный поиск Ближайших
  мест с Render во Франкфурте работать не будет. Нужен хостинг API в России
  (Yandex Cloud, VK Cloud) — отдельная задача.
