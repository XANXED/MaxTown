# Дом изолируется по Домовому чату, дубликаты допустимы

Статус: принято для хакатона, 28 сентября 2026 года. Заменяет ADR 0005; правила Ролей заменены ADR 0007.

## Контекст

Сейчас мы не можем надёжно доказать, что групповой чат MAX относится к
реальному многоквартирному дому. Наличие другого бота или адрес из ГАР не дают
такой гарантии. При этом точный адрес нужен продукту как название и исходные
данные Дома. Создатель вымышленного чата не получает доступ к данным настоящего
Домового чата: у него нет доступа к его участникам.

Для хакатона важнее сохранить строгую изоляцию данных между чатами и простой
путь подключения. Цена решения — возможные дубликаты одного реального адреса.

## Решение

- Каждый групповой чат, где MaxTown получил права администратора и определил
  Адрес Дома, создаёт отдельный Дом.
- Идентификатор Дома строится как `max-chat:<chat_id>`. Ни название чата, ни
  Адрес Дома не участвуют в определении идентичности.
- Сначала бот отправляет название чата в DaData. Если найден ровно один
  конкретный дом уровня ГАР, Дом создаётся автоматически. Иначе бот предлагает
  администратору чата открыть мини-приложение и выбрать адрес из подсказок.
- Выбранный GUID повторно проверяется сервером через DaData. Тексту адреса из
  браузера сервер не доверяет.
- Одинаковые названия и реальные адреса не объединяются. Дома из разных чатов
  не читают и не изменяют данные друг друга.
- Доступ к Дому есть только у текущих участников соответствующего Домового
  чата; сервер проверяет участие через MAX при входе.
- Наличие бота «Госуслуги Дом» не проверяется. Адрес из ГАР используется как
  подпись и метаданные, но не как доказательство официальности чата.
- Сценарий «Стать Жильцом без Приглашения» удаляется. Стать Жильцом конкретной
  Квартиры можно только по Приглашению.
- Права администратора MAX не становятся Ролью Старосты автоматически.
- После подключения бот публикует одну кнопку мини-приложения в общем чате,
  без личной рассылки всем участникам.

## Последствия

- Поддельный чат может создать только отдельный дубликат Дома для своих
  участников и не получает доступ к настоящему Дому.
- Один реальный дом может быть представлен несколькими разрозненными Домами в
  MaxTown; автоматического объединения и переноса данных нет.
- Для определения Адреса Дома нужен серверный API-ключ DaData. Без него чат
  остаётся на шаге выбора адреса и Дом не создаётся.
- Адрес не является границей данных: два чата с одним адресом создают два
  независимых Дома.
- Граница безопасности совпадает с `chat_id`, поэтому его нельзя заменять
  названием или адресом при чтении и записи данных.
