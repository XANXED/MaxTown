# Продакшн — облачный сервер Timeweb с доменом maxtown.ru; Render и Worker — запасные

Статус: принято 29 сентября 2026 года. Уточняет ADR 0010: публичный адрес —
не Cloudflare Worker, а maxtown.ru на своём сервере.

## Контекст

По ADR 0010 вся логика живёт в API на Postgres, а публичный адрес держал
Cloudflare Worker, пересылавший `/api/*` на Render во Франкфурте. Из-за
иностранного IP там не отвечает 2ГИС (ADR 0008). Кроме того, Render Free
засыпает при простое, а его бесплатная база удаляется через 30 + 14 дней. Для
продукта взят домен maxtown.ru и облачный сервер Timeweb Cloud в России.

## Решение

- Продакшн — один сервер Timeweb Cloud. docker compose: `compose.yml` (база и
  API) плюс `compose.prod.yml` (Caddy и настройки продакшна).
- Caddy сам получает сертификат Let's Encrypt для `DOMAIN`, переводит `www` на
  основной домен и передаёт всё в API. API по-прежнему сам отдаёт мини-апп,
  панель Модератора и `/api`. Порт API наружу не открыт.
- API доверяет `X-Forwarded-For` только от адресов частной сети Docker
  (`TRUST_PROXY=uniquelocal`). Лимит входа Модератора считает настоящих людей,
  а подделка заголовка извне не проходит. Число звеньев Fastify не принимает.
- Webhook бота MAX подписывается на `https://maxtown.ru/api/max/webhook`
  (`MAXTOWN_PUBLIC_URL`).
- Выкладка ручная: `./deploy/deploy.sh` на сервере. Он делает `git pull`,
  бэкап базы `pg_dump` до миграций, пересборку и проверку живого адреса.
  В GitHub нет SSH-ключей и секретов продакшна.
- Render (`render.yaml`) и Cloudflare Worker (`apps/edge`) остаются в
  репозитории как запасной путь, их проверки в CI сохраняются.

## Последствия

- С российского IP работают Ближайшие места 2ГИС. Ключ карты надо ограничить
  доменом maxtown.ru.
- Сервер и бэкапы — наша ответственность. Бэкапы лежат на том же сервере,
  их нужно копировать наружу. Обновления ОС и Docker тоже на нас.
- Образ собирается на сервере: нужно от 2 ГБ памяти или swap.
- MAX API по-прежнему подписан Russian Trusted Root CA. Без
  `NODE_EXTRA_CA_CERTS` API ходит на запасной домен MAX (ADR 0004).
- CI проверяет модель продакшна (`docker compose … config`) и контракт в
  `deploy/deployment.test.ts`, но сам на сервер не выкладывает.
