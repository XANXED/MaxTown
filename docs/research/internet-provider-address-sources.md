# Источники провайдеров и тарифов по адресу

Проверено: 28 сентября 2026 года.

## Краткий ответ

Открытого универсального API, куда можно передать адрес российского дома и
получить всех доступных интернет-Поставщиков с актуальными Тарифами, в
проверенных первичных источниках не найдено.

Рабочая схема состоит из двух независимых частей:

1. Адрес приводится к точному дому и идентификатору ГАР/ФИАС.
2. Список Поставщиков и Тарифов берётся из коммерческой адресной базы
   агрегатора или из партнёрских выгрузок отдельных операторов.

Для MaxTown наиболее короткий путь — запросить у 101 Интернет лицензионный или
партнёрский доступ к регулярно обновляемым адресным и тарифным базам. ГИС ЖКХ
может независимо подтвердить, что сеть оператора размещена в конкретном Доме,
но не содержит коммерческих Тарифов и не гарантирует подключение Квартиры. Если
условия агрегатора не подойдут, второй вариант — заключать договоры с
операторами по отдельности и сводить их выгрузки в собственную базу.

## Что подтверждено первичными источниками

### 1. 101 Интернет: наиболее близкий готовый источник

На странице сотрудничества 101 Интернет заявляет:

- более 7 млн адресов в базе и около 100 партнёрств;
- получение партнёрами тарифных и адресных баз в готовом виде с регулярным
  обновлением;
- обновление тарифов, акций и адресных баз в течение суток;
- передачу статусов заявок по API;
- контакт для партнёрства: `pr@101internet.ru`.

Отдельная страница об ИТ-деятельности подтверждает, что платформа умеет искать
услуги по адресу, сравнивать предложения и принимать заявки, а право её
использования партнёрам и лицензиатам предоставляется по лицензионному
договору. Контакт правообладателя: `welcome@promotioninternet.ru`.

Важное ограничение: на публичных страницах нет открытой спецификации API
поиска покрытия и Тарифов. Упомянутый публично API относится к передаче
статусов заявок. Поэтому наличие именно API или файлового фида, его поля,
частота обновления, география и право показывать данные пользователям должны
быть зафиксированы в договоре.

ДомИнтернет — второй кандидат для коммерческих переговоров. Его официальный
сайт сообщает, что операторы передают сервису актуальные карты покрытия, а
сервис регулярно обновляет адресные данные и Тарифы. Публичной спецификации
партнёрского API или фида не найдено; запрос можно направить на
`partners@dominternet.ru`.

### 2. ГИС ЖКХ: официальный сигнал о сети в конкретном Доме

В официальной справке ГИС ЖКХ указано, что открытая карточка Дома показывает
операторов связи, разместивших в нём свои сети. Для сети могут быть указаны
оператор, элементы оборудования и места монтажа вплоть до подъезда и этажа.

Это полезный источник начального списка Поставщиков для конкретного Дома, но с
ограничениями:

- наличие сети не доказывает наличие свободного порта или возможность
  подключения конкретной Квартиры;
- в ГИС ЖКХ нет коммерческих Тарифов домашнего интернета;
- полнота зависит от качества сведений, размещённых обязанными организациями;
- документированного анонимного API именно для массовой выгрузки сетей связи в
  Доме не найдено.

Официальная интеграция внешних информационных систем с ГИС ЖКХ использует SOAP
и требует регистрации организации и её информационной системы. Поэтому перед
автоматизацией нужно запросить у оператора ГИС ЖКХ допустимый сервис или
выгрузку; внутренние запросы веб-интерфейса не следует считать публичным API.

### 3. Прямые программы операторов: в первую очередь заявки, а не общий каталог

МТС подтверждает существование программы «МТС Агенты» и Agents API для
автоматической передачи лидов из CRM крупного агента. При передаче заявки на
фиксированные услуги рекомендуется указывать адрес. Это доказывает наличие
машинного канала для заявок, но публичная документация не подтверждает выдачу
через него полной адресной базы покрытия и Тарифов.

У билайна есть B2C-партнёрство по продаже домашнего интернета. На отдельной
странице партнёров API описан как интеграция кабинета лидогенерации с CRM и
бизнес-процессами. Публичного контракта получения покрытия всех домов на этих
страницах также нет.

Ростелеком публикует региональные формы партнёрства по продажам домашнего
интернета и оборудования. Конкретный формат адресной выгрузки нужно получать у
партнёрского менеджера.

Следствие: прямые договоры подходят, но для каждого оператора отдельно нужно
запрашивать два разных канала:

- каталог покрытия и Тарифов;
- создание заявки и получение её статуса.

### 4. ГАР/ФИАС и DaData решают только задачу адреса

ФНС публикует открытую выгрузку Государственного адресного реестра и обновляет
её еженедельно. Она помогает однозначно определить Дом, но не содержит данных
о подключённых интернет-Поставщиках.

DaData предоставляет API подсказок, стандартизации и поиска адреса по
идентификатору ГАР/ФИАС. Для связи данных нужно сохранять `house_fias_id` и
принимать только результат уровня дома. DaData отдельно предупреждает, что
идентификаторы ФИАС могут меняться, поэтому вместе с идентификатором нужно
хранить нормализованный адрес и периодически перепроверять связь.

### 5. 2ГИС не доказывает доступность в конкретном Доме

API справочника 2ГИС ищет организации и здания и возвращает сведения об
организациях. Его можно использовать, чтобы найти кандидатов в городе или
контакты локальных операторов, но наличие офиса или карточки Поставщика рядом
не является подтверждением Доступности в Доме.

## Рекомендуемый вариант для MaxTown

### Вариант A: партнёрский фид агрегатора

Написать 101 Интернет, а для сравнения условий — ДомИнтернет, и запросить
техническое и коммерческое предложение. В запросе необходимо потребовать:

1. Метод поиска по `house_fias_id` или полному нормализованному адресу.
2. Список Поставщиков, доступных именно в Доме, а не в городе или на улице.
3. Тарифы с ценой, скоростью, технологией, промопериодом, оборудованием и
   ограничениями.
4. Стабильные внешние идентификаторы Поставщика, Дома и Тарифа.
5. Полную первоначальную выгрузку и последующие изменения либо API с
   `updated_since`.
6. Дату проверки каждой записи и порядок отзыва устаревших записей.
7. Географию и полноту покрытия.
8. Право хранить данные в базе MaxTown и показывать их Жильцам.
9. Канал создания заявки, webhooks или API статусов и правила передачи
   персональных данных.
10. Тестовый контур, лимиты, SLA и стоимость.

Нельзя заранее считать, что рекламный или lead-status API включает адресный
каталог: это должно быть явно подтверждено поставщиком данных.

### Вариант B: собственная агрегация операторов

Заключить отдельные партнёрские договоры с МТС, билайном, Ростелекомом,
МегаФоном, Дом.ру и локальными операторами. Принимать их CSV/XLSX/XML/API,
нормализовать адреса до `house_fias_id` и собирать собственную связь
`Дом -> Поставщик -> Тариф`.

Этот вариант даёт больше контроля, но требует отдельного адаптера, договора и
мониторинга качества для каждого оператора.

## Как встроить источник технически

Пользовательский экран не должен опрашивать десятки внешних сайтов в момент
открытия. Данные лучше заранее синхронизировать на сервер MaxTown:

```text
партнёрский фид/API
        |
        v
проверка схемы и импорт
        |
        v
нормализация адреса -> house_fias_id
        |
        v
Дом -> Поставщик -> Тариф + source + checked_at
        |
        v
GET /api/houses/:houseId/internet-providers
```

Правила импорта:

- совпадение должно быть на уровне конкретного Дома;
- неизвестные или неоднозначные адреса не публикуются автоматически;
- удалённые из свежего фида Тарифы помечаются неактивными;
- экран показывает источник и дату проверки;
- Доступность в Доме не выдаётся за гарантию свободного порта в конкретной
  Квартире;
- окончательную техническую возможность подтверждает сам Поставщик при заявке.

Публичные формы «проверить адрес» не следует парсить как основной источник:
это нестабильный частный интерфейс без гарантированного контракта, который
может измениться или получить антибот-защиту. Пользовательское соглашение
101 Интернет дополнительно прямо запрещает автоматический сбор информации
парсерами. Для регулярного машинного импорта нужен официальный договор и явно
предоставленный API или фид.

## Следующий практический шаг

Отправить 101 Интернет короткий запрос на партнёрство с описанием MaxTown и
попросить тестовый образец адресно-тарифного фида для Москвы. Параллельно
уточнить у поддержки ГИС ЖКХ разрешённый способ получать сведения о сетях
связи по Дому. До получения ответов оставить в продукте ручное подтверждение
Старостой или Ответственным и всегда хранить `source` и `checked_at`.
